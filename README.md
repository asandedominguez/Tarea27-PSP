### Explicación del formato seleccionado:

He elegido enviar todas las palabras en una sola cadena de texto String, separadas por espacios y codificada en UTF-8, de este modo se conservan correctamente las tildes y otros caracteres especiales que se puedan utilizar, que con otros tipos de codificación no se comprenden (como la ñ). De esta forma todas las palabras viajan juntas en un único paquete UDP, evitando que lleguen desordenadas o se pierdan.
